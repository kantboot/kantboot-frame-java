1. 关于果丁智能（iSurpass ）开放服务 
 
果丁智能开 放 服 务 将 智能 门 锁 的 服 务 封 装 为 简 单 易 用 的
http/websokcet 协议、json 数据格式，第 3 方的系统或 App 很容易
与它集成。 
 
1.1. 果丁智能开放服务基本架构 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
如上图所示 
 
deviceid: dev2 
nodeid: 3 
 
 
 
 
deviceid: dev3 
 
 
 
1) iSurpass 开放服务对第 3 方系统/App 应用提供 http/websocket 接
口：http 接口用来接收第 3 方系统/App 的远程请求，websocket 
用于远程控制网关设备进入/退  添加&删除设备状态、推送设
备的 report 给第 3 方系统/App； 
iSurpass 
wifi 门锁 
第 3 方 App iSurpass 
NB-IoT 门锁 
 
 
2) iSurpass 开放服务与iSurpass 网关/设备之间采用MQTT 协议通讯； 
 
3) iSurpass 网关(或连接 iSurpass 开放服务的 NB-IoT 智能门锁、wifi
门锁)上需配置 iSurpass 开放服务的服务器地址； 
4) iSurpass 开放服务可单机部署，也可多服务器部署。 
 
 
1.2. iSurpass 开放服务的安装包 
 
iSurpass 开放服务的安装包可提供给第 3 方安装和集成，有以下版本： 
 
   for Windows：32bit or 64bit 
     for Linux：32bit or 64bit 
   for 树莓派 
 
 
2. HTTP 基础服务 
 
2.1. 认证 
 
采用 JWT 认证, see: 
https://baijiahao.baidu.com/s?id=1608021814182894637 
https://jwt.io/ 
 
 
2.1.1. JWT Token 定义 
 
◼ JWT header 
{ 
"alg": "HS256", 
"typ": "JWT" 
} 
◼ JWT payload 
{ 
 
"appkey": "<AppKey>",  #第 3 方应用的 AppKey 
"timestamp": "<TimeStamp>" #当前时间戳 
} 
◼ JWT signature 
HMACSHA256(base64UrlEncode(header) + "." + base64UrlEncode(payload), <AppSecret>) 
# AppSecret 为第 3 方应用的密钥 
◼ JWT token 
base64UrlEncode(header)+"."+base64UrlEncode(payload)+"."+signature 
 
示例： 
JWT header: 
{"alg":"HS256","typ":"JWT"} 
JWT payload: 
{"appkey":"iSurpassApp","timestamp":"1234567890"} 
AppSecret: 
iSurpass2018 
JWT token: 
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJhcHBrZXkiOiJpU3VycGFzc0FwcCIsInRpbWVzdGFtcCI6IjEyMzQ1Nj 
c4OTAifQ.KRLkB8N-3w-_tkUfUbHbZCBtZrHuOwKbmQeNK1w08_0 
 
2.1.2. JWT token 使用方式 
 
所有 HTTP 请求 Header 带 Authorization 字段，值为: 
Bearer <JWT token>

2.2.4. 获取当前连接状态 
 
方法: post 
 
请求头(header)： 
Accept-Language: <language> //en、zh-CN 
Authorization: Bearer <JWT token> 
请求参数： 
 
{ 
"method": "thing.service.GetConnectionStatus", 
"deviceid": "<deviceid>",       //网关设备ID 
"params": { 
"ForceRefresh": <true/false>  //false(缺省): 直接返回缓存,  true: 访问设备&刷新缓存后返回 
} 
} 
 
 
响应结果(Content-Type: application/json): 
 
{ 
"resultcode": 1, //1-成功 非 1-失败 
"errorinfo": "", //错误信息 
"errorinfo_cn": "", //本地化错误信息(Accept-Language 相关) 
"data": { 
"Online": <true/false>, //最新状态：true-在线 false-离线 
"LastestDateTime": "<yyyy-mm-dd HH:MM:SS>", //最新状态日期时间 
"Lastest_ts": <timestamp>,   //最新状态 Unix 时间戳(毫秒) 
"IP": "<ip>", //设备的互联网 IP 
"Network": "<network type>", //网络类型：LAN、WIFI、2G 
"Version": "<software version>", //设备的软件版本号 
"SSID": "<wifi ssid>", //WIFI SSID 
"WIFI_IP": "<wifi ip>", //WIFI IP 
"WIFI_MAC": "<wifi mac>", //WIFI MAC 
"RSSI": <value> //wifi 或蜂窝移动信号强度值 
} 
} 
【注】 
1）该接口仅适用于 z-wave 网关 
 
 
[示例] 
curl -X POST \ 
http://112.74.20.113:8888/gateway \

url: ws://<ip>:<port>/ws/addDelDevice 
encoding: UTF-8

{"method":"thing.service.QuitAddDelDeviceStatus", "deviceid":"<deviceid>"}
